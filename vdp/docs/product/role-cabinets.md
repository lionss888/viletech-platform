# Кабинеты ролей

Top tasks ориентир для IA и help-контента. Матрица действий живёт в core, не в BDUI schema.

## User

Создать или дополнить заявку. Загрузить документы по этапу. Увидеть статус и что дальше. Подтвердить получение.

Primary term. Заявка. Реестр Мои заявки. Completed label Сделка закрыта.

## Internal compliance ICO

Очередь review организаций и заявок. Approve reject request fixes. Чеклист org без лишних ПДн в UI чужой зоны.

Primary term. Заявка и организация.

## External compliance ECO

Review сделки и документов. Accept reject. Понятный corrections path для User.

Primary term. Сделка. Очередь сделок N.

## Manager

Очередь назначения. Выбрать провайдера. Contract order payment refund report shipment. Контроль зависаний.

Primary term. Сделка. CTA Закрыть сделку.

## Provider

Принять assigned. Исполнить платёж. Подтвердить платёжку или хеш. Без ПДн клиента.

Primary term. Платеж. Реестр Платежи в исполнении.

## Bank channel UI

Badge канала, correlation id, webhook и commission settings. Не отдельный кабинет bank role в MVP. API login bank@vdp.local.

## Root superadmin

Dashboard services incidents stuck forms. /admin accounts. /testing scenarios. Union CTA и cancel. Wording root вне scope RW copy programs.

## Guided next step

На карточке заявки блок следующего шага строится из доменной матрицы роли, не из догадок UI. Disabled primary с краткой причиной.
