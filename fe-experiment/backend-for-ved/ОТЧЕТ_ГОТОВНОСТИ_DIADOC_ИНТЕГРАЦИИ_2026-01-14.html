Реализованные возможности

Методы Diadoc API

  • ✅ Аутентификация через DiadocAuth (ddauth_api_client_id + ddauth_token)
  • ✅ Загрузка документов (PostMessage V3)
  • ✅ Загрузка XML документов (PostMessage V3 + XML генерация)
  • ✅ Получение статуса документов (GetMessage V6)
  • ✅ Скачивание подписанных документов (GetEntityContent V4)
  • ✅ Поиск организаций по ИНН (GetOrganizationsByInnKpp)

Бизнес-функционал (VF-2)

  • ✅ Выбор способа подписи — paymentOrderSignMethod, reportSignMethod ('manual' | 'diadoc')
  • ✅ Генерация XML документов — Invoice, Torg12, AcceptanceCertificate, УПД
  • ✅ Промежуточные статусы — REPORT_WAITING_DIADOC, WAITING_DIADOC
  • ✅ 3-дневное уведомление — DiadocExpirationCheckerService
  • ✅ Автоприкрепление подписанного PDF — улучшенный выбор с приоритетами

🔒 Безопасность webhook

  • ✅ Аутентификация — проверка секрета (timing-safe)
  • ✅ IP whitelist — поддержка CIDR нотации
  • ✅ Replay protection — timestamp + nonce cache
  • ✅ Rate limiting — 10 запросов/минуту на IP
  • ✅ Валидация payload — проверка структуры

Конфигурация

Все переменные окружения определены в src/config.ts и .env.example:

# Основные настройки
DIADOC_ENABLED=true
DIADOC_API_URL=https://diadoc-api.kontur.ru
DIADOC_API_CLIENT_ID=ваш-guid-ключа-разработчика
DIADOC_BOX_ID=ваш-box-id@diadoc.ru
DIADOC_AUTH_TOKEN=ваш-токен

# Безопасность webhook
DIADOC_WEBHOOK_SECRET=секретный-ключ-для-webhook
DIADOC_WEBHOOK_ALLOWED_IPS=185.71.76.0/24,185.71.77.0/24
DIADOC_WEBHOOK_MAX_AGE_SECONDS=300

Заключение

Интеграция с Diadoc API готова к использованию (PREPRODUCTION-READY).

Для активации необходимо:

  1. Получить учётные данные от провайдера (Контур/Диадок)
  2. Добавить их в переменные окружения
  3. Настроить секрет для webhook (рекомендуется)
  4. Перезапустить приложение

После этого интеграция будет полностью функциональна.
