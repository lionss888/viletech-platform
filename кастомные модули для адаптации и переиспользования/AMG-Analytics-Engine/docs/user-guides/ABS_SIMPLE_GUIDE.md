# Простое руководство по работе с АБС

## Что такое АБС?

АБС (Автоматизированная банковская система) - это программа для управления банковскими данными. Она помогает хранить информацию о клиентах, их счетах и денежных переводах.

## Как запустить систему?

### Шаг 1: Запуск программы
1. Откройте папку с программой
2. Дважды кликните на файл `start.bat` (Windows) или выполните команду в терминале:
   ```
   docker-compose up -d
   ```

### Шаг 2: Открытие веб-интерфейса
1. Откройте браузер (Chrome, Firefox, Safari)
2. Введите адрес: `http://localhost:5050`
3. Нажмите Enter

### Шаг 3: Вход в систему
1. В поле "Email" введите: `admin@example.com`
2. В поле "Пароль" введите: `PgAdmin2024@Secure!Interface#`
3. Нажмите кнопку "Войти"

## Что можно делать в системе?

### 1. Просмотр клиентов
1. Разверните ваш сервер в левой панели
2. Найдите папку "Tables"
3. Правый клик на "clients" → "View/Edit Data" → "All Rows"
4. Вы увидите список всех клиентов банка

**Что показывает таблица клиентов:**
- **ID** - номер клиента
- **First Name** - имя
- **Last Name** - фамилия
- **Tax ID** - ИНН
- **Created At** - дата регистрации

### 2. Просмотр счетов
1. Правый клик на "accounts" → "View/Edit Data" → "All Rows"
2. Вы увидите все банковские счета

**Что показывает таблица счетов:**
- **ID** - номер счета в системе
- **Account Number** - номер банковского счета
- **Client ID** - номер клиента
- **Type** - тип счета (расчетный, депозитный и т.д.)
- **Currency** - валюта (RUB, USD, EUR)
- **Balance** - остаток на счете
- **Opened Date** - дата открытия счета
- **Is Active** - активен ли счет

### 3. Просмотр транзакций
1. Правый клик на "transactions" → "View/Edit Data" → "All Rows"
2. Вы увидите все денежные переводы

**Что показывает таблица транзакций:**
- **ID** - номер операции
- **Debit Account ID** - счет, с которого списали деньги
- **Credit Account ID** - счет, на который зачислили деньги
- **Amount** - сумма перевода
- **Currency** - валюта
- **Description** - описание операции
- **Status** - статус (выполнено, ожидает, отменено)
- **Created At** - дата создания операции

## Как выполнить простые запросы?

### Поиск клиента по ИНН:
1. Нажмите на значок SQL (молния) в верхней панели
2. Введите команду:
   ```sql
   SELECT * FROM clients WHERE tax_id = 'INN0000000001';
   ```
3. Нажмите кнопку "Execute" (▶️)

### Подсчет количества клиентов:
```sql
SELECT COUNT(*) as "Всего клиентов" FROM clients;
```

### Просмотр активных счетов:
```sql
SELECT * FROM active_accounts_view;
```

## Часто используемые команды

### Посмотреть всех клиентов:
```sql
SELECT first_name, last_name, tax_id FROM clients;
```

### Посмотреть счета конкретного клиента:
```sql
SELECT * FROM accounts WHERE client_id = 1;
```

### Посмотреть транзакции за сегодня:
```sql
SELECT * FROM transactions WHERE DATE(created_at) = CURRENT_DATE;
```

### Посчитать общий баланс по валютам:
```sql
SELECT currency, SUM(balance) as "Общий баланс" 
FROM accounts 
WHERE is_active = true 
GROUP BY currency;
```

## Что означают статусы транзакций?

- **pending** - ожидает выполнения
- **completed** - выполнена успешно
- **failed** - не удалась
- **cancelled** - отменена

## Типы счетов

- **Расчетный** - обычный банковский счет
- **Депозитный** - счет для хранения денег под проценты
- **Кредитный** - счет с кредитным лимитом
- **Сберегательный** - счет для накоплений
- **Корпоративный** - счет для организаций

## Валюты в системе

- **RUB** - российский рубль
- **USD** - доллар США
- **EUR** - евро
- **CNY** - китайский юань

## Решение проблем

### Система не запускается:
1. Проверьте, что Docker запущен
2. Убедитесь, что порты 5432 и 5050 свободны
3. Перезапустите систему: `docker-compose down && docker-compose up -d`

### Не могу войти в систему:
1. Проверьте правильность пароля
2. Убедитесь, что система запущена
3. Попробуйте обновить страницу

### Не вижу данные:
1. Проверьте подключение к серверу
2. Убедитесь, что выбрана правильная база данных
3. Обновите данные (кнопка 🔄)
