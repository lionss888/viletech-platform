# ChatGPT Style Design - AMG Dashboard

## Обзор

AMG Dashboard теперь использует современный минималистичный дизайн в стиле ChatGPT, обеспечивающий отличный пользовательский опыт и современный внешний вид.

## 🎨 Особенности дизайна

### Цветовая палитра
- **Основной фон:** `#ffffff` (белый)
- **Вторичный фон:** `#f7f7f8` (светло-серый)
- **Основной текст:** `#2d3748` (темно-серый)
- **Вторичный текст:** `#4a5568` (серый)
- **Приглушенный текст:** `#718096` (светло-серый)
- **Акцентный цвет:** `#10a37f` (зелено-синий)
- **Границы:** `#e2e8f0` (светло-серый)

### Типографика
- **Шрифт:** -apple-system, BlinkMacSystemFont, 'Segoe UI', 'Roboto'
- **Заголовки:** 700 weight для H1, 600 weight для H2-H3
- **Текст:** 400 weight для основного текста, 500 weight для кнопок
- **Размеры:** От 0.75rem до 1.875rem

### Компоненты

#### Навигация
- Минималистичная навигационная панель
- Плавные переходы при наведении
- Активные состояния с цветовым акцентом
- Адаптивное меню для мобильных устройств

#### Карточки
- Скругленные углы (12px)
- Мягкие тени с hover-эффектами
- Анимация поднятия при наведении
- Четкая иерархия информации

#### Кнопки
- Три варианта: primary, secondary, ghost
- Плавные переходы и анимации
- Эффект поднятия для primary кнопок
- Адаптивные размеры

#### Формы
- Четкие лейблы и поля ввода
- Фокус-состояния с цветовым акцентом
- Валидация с визуальной обратной связью
- Доступность для всех пользователей

## 📱 Адаптивность

### Мобильные устройства
- Сетка переключается на одну колонку
- Уменьшенные размеры заголовков
- Оптимизированные отступы
- Touch-friendly элементы

### Планшеты
- Адаптивная сетка (2-3 колонки)
- Промежуточные размеры шрифтов
- Оптимизированная навигация

### Десктоп
- Полная функциональность
- Максимальная ширина 1200px
- Оптимальные отступы и размеры

## 🎭 Анимации и переходы

### Основные принципы
- **Длительность:** 0.2s для основных переходов
- **Функция:** ease-in-out для плавности
- **Минимализм:** только необходимые анимации

### Типы анимаций
- **Hover-эффекты:** изменение цвета и тени
- **Focus-состояния:** подсветка активных элементов
- **Загрузка:** fade-in анимация для контента
- **Переходы:** плавное изменение состояний

## 🛠️ Техническая реализация

### CSS переменные
```css
:root {
  --chatgpt-bg-primary: #ffffff;
  --chatgpt-text-primary: #2d3748;
  --chatgpt-accent-blue: #10a37f;
  --chatgpt-transition: all 0.2s ease-in-out;
}
```

### Компоненты Streamlit
- Кастомные HTML/CSS компоненты
- Интеграция с Streamlit widgets
- Responsive дизайн через CSS Grid и Flexbox
- Оптимизация производительности

### Файлы
- `chatgpt_style.css` - основные стили
- `chatgpt_components.py` - компоненты для Streamlit
- Интеграция в `amg_dashboard.py`
