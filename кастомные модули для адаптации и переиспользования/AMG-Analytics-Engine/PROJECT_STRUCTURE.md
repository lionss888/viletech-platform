# Структура проекта АБС

```
AMG/
├── README.md                    # Основная документация проекта
├── docker-compose.yml           # Конфигурация Docker контейнеров
├── PROJECT_STRUCTURE.md         # Этот файл
│
├── 📁 config/                   # Конфигурационные файлы
│   ├── README.md               # Описание конфигурации
│   ├── 📁 environments/        # Переменные окружения
│   │   ├── .env               # Активные настройки
│   │   └── env.example        # Шаблон настроек
│   └── 📁 security/           # Настройки безопасности (будущее)
│
├── 📁 database/                # База данных
│   ├── README.md              # Описание БД
│   ├── 📁 schemas/            # Схемы БД
│   │   ├── init.sql          # Основная схема
│   │   └── superadmin_setup.sql # Настройка суперадминистратора
│   ├── 📁 data/              # Тестовые данные
│   │   ├── correct_data.sql  # Корректные данные
│   │   ├── sample_data.sql   # Расширенные данные
│   │   └── simple_data.sql   # Простые данные
│   └── 📁 migrations/        # Миграции БД (будущее)
│
├── 📁 docs/                   # Документация
│   ├── README.md             # Навигация по документации
│   ├── 📁 user-guides/       # Руководства пользователей
│   │   └── ABS_SIMPLE_GUIDE.md # Простое руководство
│   ├── 📁 technical/         # Техническая документация
│   │   └── ABS_DATABASE_DOCUMENTATION.md # Документация БД
│   ├── 📁 admin/             # Документация администраторов
│   │   └── SUPERADMIN_ACCESS.md # Доступ суперадминистратора
│   ├── 📁 development/       # Документация разработчиков
│   │   └── TECHNICAL_SPECIFICATION.md # Техническая спецификация
│   └── 📁 deployment/        # Документация развертывания (будущее)
│
└── 📁 scripts/                # Скрипты
    ├── README.md             # Описание скриптов
    ├── 📁 setup/             # Скрипты установки
    │   ├── start.bat        # Запуск на Windows
    │   └── start.sh         # Запуск на macOS/Linux
    ├── 📁 maintenance/      # Скрипты обслуживания (будущее)
    └── 📁 backup/           # Скрипты резервного копирования (будущее)
```

## Назначение папок

### 📁 config/
**Конфигурационные файлы системы**
- Переменные окружения
- Настройки безопасности
- Параметры подключения

### 📁 database/
**Все, что связано с базой данных**
- Схемы и структура
- Тестовые данные
- Миграции для обновлений

### 📁 docs/
**Документация для разных пользователей**
- Простые руководства для новичков
- Техническая документация для специалистов
- Инструкции для администраторов
- Спецификации для разработчиков

### 📁 scripts/
**Автоматизация и утилиты**
- Скрипты запуска системы
- Инструменты обслуживания
- Автоматическое резервное копирование

## Принципы организации

### 🎯 **Разделение по ролям**
- Каждый тип пользователя находит документацию в своей папке
- Четкое разделение между пользовательской и технической документацией

### 🔄 **Версионирование**
- Папка migrations для отслеживания изменений БД
- Возможность отката к предыдущим версиям

### 🛡️ **Безопасность**
- Конфигурационные файлы отделены от кода
- Чувствительные данные не попадают в систему контроля версий

### 🚀 **Масштабируемость**
- Структура готова для добавления новых модулей
- Легко добавлять новые типы документации

## Рекомендации по использованию

### Для новых пользователей:
1. Начните с `docs/user-guides/ABS_SIMPLE_GUIDE.md`
2. Используйте `scripts/setup/start.bat` или `start.sh` для запуска

### Для администраторов:
1. Изучите `docs/admin/SUPERADMIN_ACCESS.md`
2. Настройте `config/environments/.env`
3. Используйте `database/` для управления данными

### Для разработчиков:
1. Изучите `docs/development/TECHNICAL_SPECIFICATION.md`
2. Работайте со схемами в `database/schemas/`
3. Добавляйте миграции в `database/migrations/`

### Для технических специалистов:
1. Изучите `docs/technical/ABS_DATABASE_DOCUMENTATION.md`
2. Настройте мониторинг через `scripts/maintenance/`
3. Настройте автоматические бэкапы через `scripts/backup/`
