# Отчет о проекте AMG Banking Core для группы разработки

**Дата создания:** 20 сентября 2025  
**Статус:** Готов к разработке  
**Версия:** 1.0  

## 📋 Краткое описание проекта

**AMG Banking Core** - это полнофункциональная автоматизированная банковская система (АБС), построенная на современном технологическом стеке с интеграцией AI/LLM функций. Система готова к развертыванию и дальнейшей разработке.

### Ключевые особенности:
- 🏦 **Банковское ядро** - PostgreSQL с полной схемой клиентов, счетов и транзакций
- 🤖 **AI интеграция** - Ollama для языковых моделей и аналитики
- 📊 **Аналитический дашборд** - Streamlit с визуализацией данных
- 🔍 **Система мониторинга** - Prometheus, Grafana, Elasticsearch, Kibana
- 🔐 **Безопасность** - Многоуровневая система прав доступа
- 📦 **Контейнеризация** - Docker для легкого развертывания

## 🗄️ База данных

### Основные таблицы
```sql
-- Клиенты
clients (id, first_name, last_name, tax_id, created_at)

-- Счета  
accounts (id, account_number, client_id, type, currency, balance, opened_date, is_active)

-- Транзакции
transactions (id, debit_account_id, credit_account_id, amount, currency, description, status, created_at, executed_at)
```

### Система безопасности
- **Суперадминистратор:** `lionss` / `lionss2025` (уровень прав 10)
- **Администратор:** `abs_admin` (уровень прав 6-9)
- **Оператор:** `abs_operator` (уровень прав 3-5)
- **Только чтение:** `abs_readonly` (уровень прав 1-2)

### Представления
- `active_accounts_view` - активные счета с данными клиентов
- `transactions_view` - детальная информация о транзакциях

## 🚀 Быстрый запуск

### 1. Подготовка
```bash
# Клонирование и настройка
cd /path/to/AMG
cp config/environments/env.example config/environments/.env
```

### 2. Запуск основных сервисов
```bash
# Автоматический запуск
./scripts/setup/start.sh

# Или вручную
docker-compose up -d
```

### 3. Запуск системы мониторинга
```bash
docker-compose -f docker/monitoring/docker-compose.monitoring.yml up -d
```

### 4. Проверка статуса
```bash
docker-compose ps
```

## 🔧 API Endpoints (рекомендуемые)

### Клиенты
```
GET    /api/clients              # Список клиентов
GET    /api/clients/{id}         # Клиент по ID
POST   /api/clients              # Создание клиента
PUT    /api/clients/{id}         # Обновление клиента
DELETE /api/clients/{id}         # Удаление клиента (только суперадмин)
```

### Счета
```
GET    /api/accounts             # Список счетов
GET    /api/accounts/{id}        # Счет по ID
GET    /api/clients/{id}/accounts # Счета клиента
POST   /api/accounts             # Создание счета
PUT    /api/accounts/{id}        # Обновление счета
```

### Транзакции
```
GET    /api/transactions         # Список транзакций
GET    /api/transactions/{id}    # Транзакция по ID
POST   /api/transactions         # Создание транзакции
PUT    /api/transactions/{id}    # Обновление статуса
```

## 📊 Мониторинг и логирование

### Система мониторинга включает:
- **Prometheus** - сбор метрик
- **Grafana** - визуализация данных
- **Elasticsearch** - хранение логов
- **Kibana** - анализ логов
- **Fluentd** - сбор логов
- **Alertmanager** - уведомления

### Ключевые метрики:
- Время отклика API
- Количество активных соединений
- Размер таблиц БД
- Количество транзакций в секунду
- Использование ресурсов системы

## 🔐 Безопасность

### Защитные механизмы:
- Пароли хранятся в отдельном файле `.env`
- Контейнеры изолированы от основной системы
- Данные сохраняются в именованных Docker volumes
- Row Level Security (RLS) включен
- Автоматический аудит критических операций
- Защита от удаления учетной записи владельца

### Иерархия прав:
- **Уровень 10:** Суперадминистратор (полный контроль)
- **Уровень 6-9:** Администраторы (без удаления)
- **Уровень 3-5:** Операторы (ограниченные права)
- **Уровень 1-2:** Пользователи (только чтение)
