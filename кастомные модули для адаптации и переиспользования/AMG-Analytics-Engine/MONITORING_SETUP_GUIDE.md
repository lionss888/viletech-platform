# ИНСТРУКЦИЯ ПО НАСТРОЙКЕ МОНИТОРИНГА AMG BANKING CORE

## 🎯 Что уже настроено:

### ✅ Работающие сервисы:
- **Grafana** - http://localhost:3000 (admin/admin123)
- **Prometheus** - http://localhost:9090
- **Node Exporter** - порт 9100 (системные метрики)
- **cAdvisor** - порт 8080 (метрики контейнеров)

### 📊 Готовый дашборд:
- Создан дашборд 'AMG Banking Core - Обзор системы'
- Включает метрики CPU, памяти, диска, HTTP запросов
- Мониторинг статуса всех сервисов

## 🔧 Как настроить мониторинг:

### Шаг 1: Открыть Grafana
1. Перейти по адресу: http://localhost:3000
2. Логин: admin, пароль: admin123

### Шаг 2: Добавить источник данных Prometheus
1. Configuration → Data Sources
2. Add data source → Prometheus
3. URL: http://prometheus:9090
4. Save & Test

### Шаг 3: Импортировать дашборд
1. Dashboards → Import
2. Upload JSON file: amg-overview.json
3. Выбрать Prometheus как источник данных
4. Import

## 📈 Что можно мониторить:

### Системные метрики:
- CPU, память, диск
- Сетевой трафик
- Процессы и контейнеры

### Метрики приложений:
- HTTP запросы и время ответа
- Активные пользователи
- Транзакции и ошибки

### Статус сервисов:
- Доступность всех компонентов
- Время отклика
- Количество ошибок
