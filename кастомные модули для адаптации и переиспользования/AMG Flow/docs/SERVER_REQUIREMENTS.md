# Требования к серверам для Ollama BP Automation

**Дата:** 1 января 2025  
**Версия:** 1.0

## 🎯 Обзор

Данный документ описывает требования к серверному оборудованию для развертывания системы Ollama BP Automation с учетом производительности и масштабируемости.

## 📊 Факторы производительности

### 1. **RAM (Оперативная память) - КРИТИЧНО (80% влияния)**

| Размер модели | Параметры | Требуемая RAM | Рекомендуемая RAM |
|---------------|-----------|---------------|-------------------|
| **Малые** | 3B | 4-6 GB | 8 GB |
| **Средние** | 7B-13B | 8-16 GB | 16-32 GB |
| **Большие** | 30B-70B | 32-64 GB | 64-128 GB |
| **Огромные** | 70B+ | 64+ GB | 128+ GB |

**Текущие модели в проекте:**
- `llama3.2:latest` (3.2B) - требует 4-6GB RAM
- `codellama:latest` (7B) - требует 8-12GB RAM

### 2. **CPU (Процессор) - 15% влияния**

| Нагрузка | Ядра | Частота | Архитектура |
|----------|------|---------|-------------|
| **Минимальная** | 2-4 | 2.0+ GHz | x86_64 |
| **Рекомендуемая** | 4-8 | 2.5+ GHz | x86_64 |
| **Высокая** | 8-16 | 3.0+ GHz | x86_64 |
| **Профессиональная** | 16+ | 3.5+ GHz | x86_64 |

### 3. **GPU (Графический процессор) - ОПЦИОНАЛЬНО**

| GPU | VRAM | Производительность | Рекомендация |
|-----|------|-------------------|--------------|
| **RTX 4090** | 24GB | Очень высокая | Профессиональное использование |
| **RTX 3090** | 24GB | Высокая | Высокая нагрузка |
| **RTX 3080** | 10GB | Средняя | Средняя нагрузка |
| **RTX 3060** | 12GB | Базовая | Бюджетный вариант |

### 4. **Диск (Хранилище) - 5% влияния**

| Тип | Размер | Скорость | Рекомендация |
|-----|--------|----------|--------------|
| **SSD NVMe** | 100GB+ | Очень высокая | Рекомендуется |
| **SSD SATA** | 100GB+ | Высокая | Хорошо |
| **HDD** | 200GB+ | Низкая | Не рекомендуется |

## 🏗️ Конфигурации серверов

### 🟢 **Бюджетный вариант ($50-100/месяц)**

**Назначение:** Разработка, тестирование, демо
```
RAM: 16GB DDR4
CPU: 4 ядра, 2.5GHz (Intel i5/AMD Ryzen 5)
Диск: 100GB SSD
Сеть: 1Gbps
Модели: до 7B параметров
Производительность: 1-2 токена/сек
```

**Провайдеры:**
- DigitalOcean: $96/месяц (16GB RAM)
- Linode: $96/месяц (16GB RAM)
- Vultr: $80/месяц (16GB RAM)

### 🟡 **Средний вариант ($100-300/месяц)**

**Назначение:** Продакшен, средняя нагрузка
```
RAM: 32GB DDR4
CPU: 8 ядер, 3.0GHz (Intel i7/AMD Ryzen 7)
Диск: 200GB SSD NVMe
Сеть: 2Gbps
Модели: до 13B параметров
Производительность: 3-5 токенов/сек
```

**Провайдеры:**
- AWS EC2: r5.2xlarge ($200/месяц)
- Google Cloud: n2-standard-8 ($250/месяц)
- Azure: D8s_v3 ($220/месяц)

### 🔴 **Профессиональный ($300-800/месяц)**

**Назначение:** Высокая нагрузка, коммерческое использование
```
RAM: 64GB DDR4
CPU: 16 ядер, 3.5GHz (Intel Xeon/AMD EPYC)
GPU: NVIDIA RTX 4090 (24GB VRAM)
Диск: 500GB SSD NVMe
Сеть: 10Gbps
Модели: до 70B параметров
Производительность: 10-20 токенов/сек
```

**Провайдеры:**
- AWS EC2: p3.2xlarge ($600/месяц)
- Google Cloud: a2-highgpu-1g ($800/месяц)
- Azure: NC6s_v3 ($500/месяц)

### 🚀 **Enterprise ($800+/месяц)**

**Назначение:** Критически важные системы
```
RAM: 128GB+ DDR4
CPU: 32+ ядер, 4.0GHz
GPU: 2x NVIDIA RTX 4090 или A100
Диск: 1TB+ SSD NVMe
Сеть: 25Gbps+
Модели: любые размеры
Производительность: 50+ токенов/сек
```

## ⚡ Оптимизация производительности

### **Настройки Ollama**

```bash
# Ограничение параллельных запросов
OLLAMA_NUM_PARALLEL=1

# Максимум загруженных моделей
OLLAMA_MAX_LOADED_MODELS=1

# Таймауты
OLLAMA_KEEP_ALIVE=5m
OLLAMA_HOST=0.0.0.0:11434
```

### **Рекомендуемые модели по производительности**

| Модель | Размер | RAM | Скорость | Качество |
|--------|--------|-----|----------|----------|
| **llama3.2:3b** | 3.2B | 4GB | Очень быстро | Хорошее |
| **llama3.2:8b** | 8B | 8GB | Быстро | Отличное |
| **codellama:7b** | 7B | 8GB | Быстро | Код |
| **mistral:7b** | 7B | 8GB | Быстро | Универсальное |
| **llama3.1:70b** | 70B | 64GB | Медленно | Превосходное |

### **Квантованные модели (рекомендуется)**

```bash
# Быстрые квантованные версии
llama3.2:3b-instruct-q4_0    # 4GB RAM
llama3.2:8b-instruct-q4_0    # 8GB RAM
codellama:7b-instruct-q4_0   # 8GB RAM
mistral:7b-instruct-q4_0     # 8GB RAM
```

## 📈 Мониторинг производительности

### **Ключевые метрики**

1. **Время отклика** - должно быть < 5 секунд
2. **Пропускная способность** - токены в секунду
3. **Использование RAM** - не более 90%
4. **Загрузка CPU** - не более 80%
5. **Латентность сети** - < 100ms

### **Команды мониторинга**

```bash
# Проверка статуса Ollama
curl http://localhost:11434/api/tags

# Проверка здоровья API
curl http://localhost:8000/v1/health/ollama

# Мониторинг ресурсов
htop
nvidia-smi  # для GPU
```

## 🔧 Быстрые улучшения

### **1. Оптимизация текущей настройки**

```bash
# Замените большие модели на квантованные
docker exec ollama ollama pull llama3.2:3b-instruct-q4_0
docker exec ollama ollama pull codellama:7b-instruct-q4_0

# Удалите большие модели
docker exec ollama ollama rm llama3.2:latest
docker exec ollama ollama rm codellama:latest
```

### **2. Настройка переменных окружения**

```bash
# Добавьте в .env
OLLAMA_NUM_PARALLEL=1
OLLAMA_MAX_LOADED_MODELS=1
OLLAMA_KEEP_ALIVE=5m
```

### **3. Мониторинг производительности**

```bash
# Скрипт для мониторинга
#!/bin/bash
while true; do
  echo "=== $(date) ==="
  curl -s http://localhost:8000/v1/health/ollama | jq
  free -h
  echo ""
  sleep 30
done
```
