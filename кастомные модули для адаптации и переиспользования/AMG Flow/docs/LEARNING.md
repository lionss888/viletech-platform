# 🧠 Обучение модели на ваших диалогах

## 📋 Обзор

AMG Flow теперь поддерживает обучение модели на ваших диалогах! Это позволяет создавать персонализированные AI-ассистенты, которые лучше понимают ваш контекст и стиль общения.

## 🚀 Подходы к обучению

### 1. RAG (Retrieval-Augmented Generation) - Рекомендуется
- **Быстрый старт** - работает сразу
- **Низкие ресурсы** - не требует переобучения модели
- **Безопасность** - ваши данные остаются приватными
- **Гибкость** - легко добавлять новые данные

### 2. Fine-tuning (Тонкая настройка)
- **Персонализация** - создает специализированную модель
- **Высокие ресурсы** - требует значительных вычислений
- **Время** - процесс может занять часы
- **Качество** - более глубокое понимание контекста

## 🛠️ Быстрый старт

### Шаг 1: Запуск системы
```bash
# Запустить все сервисы
make dev

# Или с Docker
docker compose up --build
```

### Шаг 2: Добавление бесед в RAG
```bash
# Добавить конкретную беседу
make add-to-rag CONVO_ID=your-conversation-id

# Или через API
curl -X POST "http://localhost:8000/v1/learning/rag/add-conversation?convo_id=your-conversation-id"
```

### Шаг 3: Использование RAG в чате
```bash
# Отправить сообщение с RAG
curl -X POST http://localhost:8000/v1/ask \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama3.2:3b-instruct-q4_0",
    "messages": [{"role": "user", "content": "Привет!"}],
    "convo_id": "test-123",
    "use_rag": true
  }'
```

## 📊 RAG система

### Статистика RAG
```bash
# Посмотреть статистику
make rag-stats

# Или через API
curl http://localhost:8000/v1/learning/rag/stats
```

**Ответ:**
```json
{
  "total_chunks": 150,
  "total_embeddings": 150,
  "unique_conversations": 25
}
```

### Как работает RAG

1. **Сбор данных** - ваши диалоги сохраняются в векторном хранилище
2. **Поиск контекста** - при новом запросе система находит релевантные фрагменты
3. **Усиление промпта** - найденный контекст добавляется к системному промпту
4. **Генерация ответа** - модель использует контекст для более точных ответов

## 🎯 Fine-tuning модели

### Подготовка данных
```bash
# Экспортировать данные для обучения
make export-data

# Или для конкретной беседы
./scripts/train_model.sh -x -c your-conversation-id
```

### Обучение модели
```bash
# Обучить на всех беседах
make train

# Обучить на конкретной беседе
make train-conversation CONVO_ID=your-conversation-id

# Кастомные параметры
./scripts/train_model.sh \
  --base-model llama3.2:3b-instruct-q4_0 \
  --new-model-name my-custom-model \
  --epochs 5 \
  --learning-rate 0.0001
```

### Параметры обучения

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `--base-model` | Базовая модель | `llama3.2:3b-instruct-q4_0` |
| `--new-model-name` | Имя новой модели | `amg-flow-custom` |
| `--epochs` | Количество эпох | `3` |
| `--learning-rate` | Скорость обучения | `0.0001` |
| `--convo-id` | ID конкретной беседы | Все беседы |

## 🔧 API Endpoints

### RAG система
- `GET /v1/learning/rag/stats` - статистика RAG
- `POST /v1/learning/rag/add-conversation` - добавить беседу в RAG

### Обучение модели
- `GET /v1/learning/training/data` - получить данные для обучения
- `POST /v1/learning/training/export` - экспортировать данные
- `POST /v1/learning/training/train` - запустить обучение
- `GET /v1/learning/models` - список доступных моделей
- `DELETE /v1/learning/models/{name}` - удалить модель

## 💡 Рекомендации

### Для RAG (рекомендуется для начала)
1. **Начните с RAG** - быстрый результат без больших ресурсов
2. **Добавляйте качественные беседы** - чем лучше данные, тем лучше результат
3. **Мониторьте статистику** - следите за количеством добавленных данных
4. **Тестируйте регулярно** - проверяйте качество ответов

### Для Fine-tuning
1. **Соберите достаточно данных** - минимум 100-500 качественных примеров
2. **Проверьте качество данных** - удалите низкокачественные беседы
3. **Начните с малого** - используйте 1-2 эпохи для начала
4. **Оценивайте результаты** - сравнивайте с базовой моделью

## 🆘 Устранение неполадок

### RAG не работает
```bash
# Проверить статус RAG
curl http://localhost:8000/v1/learning/rag/stats

# Перезапустить API
docker compose restart api
```

### Обучение не запускается
```bash
# Проверить доступность Ollama
curl http://localhost:11434/api/tags

# Проверить логи
docker compose logs api | grep -i training
```

### Низкое качество ответов
1. **Добавьте больше качественных данных**
2. **Проверьте релевантность контекста**
3. **Настройте параметры поиска**
4. **Попробуйте разные модели**
