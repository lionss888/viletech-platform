
## 🏷️ Типы изменений

- **🚀 Feature** - Новая функциональность
- **🐛 Bugfix** - Исправление ошибок
- **🧹 Refactor** - Рефакторинг кода
- **📚 Docs** - Изменения в документации
- **🔧 Config** - Изменения конфигурации
- **⚡ Performance** - Улучшения производительности
- **🔒 Security** - Исправления безопасности
- **🗑️ Cleanup** - Удаление устаревшего кода

## 📖 Формат записи

Каждая запись должна содержать:

1. **Заголовок** с эмодзи и кратким описанием
2. **Метаданные** (дата, тип, статус)
3. **Обзор изменений**
4. **Детальное описание**
5. **Влияние на проект**
6. **Инструкции по миграции** (если нужны)

## 🔍 Поиск изменений

Для поиска конкретных изменений используйте:

```bash
# Поиск по ключевому слову
grep -r "analytics" docs/changelog/

# Поиск по дате
ls docs/changelog/2025-01-*

# Поиск по типу изменений
grep -r "🧹 Refactor" docs/changelog/
```

## 📝 Добавление новых записей

При внесении значимых изменений в проект:

1. Создайте новый файл с датой и описанием
2. Используйте шаблон существующих записей
3. Обновите таблицу в этом README
4. Добавьте соответствующие теги и эмодзи
