# 📋 Техническое описание проекта AMG Flow

**Дата:** 1 января 2025  
**Версия:** 1.0  
**Статус:** Готово к передаче

## 🎯 Назначение проекта

**AMG Flow** - система автоматизации бизнес-процессов с интеграцией AI-моделей через Ollama. Предназначена для автоматизации рутинных задач, анализа данных и интеллектуальной поддержки пользователей.

## 🏗️ Архитектурные принципы

### Разделение ответственности
- **Go (ядро)** - бизнес-логика, валидация, управление состоянием
- **Python (аналитика/AI)** - только аналитика, AI, ML-интеграции
- **UI (рендер по схемам)** - Backend-Driven UI подход

### Взаимодействие компонентов
- Go ↔ Python через HTTP/gRPC
- Frontend получает JSON-схемы UI от backend
- Централизованное управление состоянием в Go

## 📊 Текущее состояние

### ✅ Готово (100%)
- **AI-чат с RAG** - полная функциональность
- **Python Analytics API** - работает, но содержит бизнес-логику
- **PostgreSQL** - настроена и работает
- **Docker** - полная контейнеризация
- **Blue-Green deployment** - реализован

### 🔄 В разработке
- **Go Backend** - 40% готов (создана структура, есть заглушки)
- **BDUI** - 20% готов (только API заглушки)
- **Python рефакторинг** - требуется перенос бизнес-логики в Go

## 🚨 Критические проблемы

### 1. Нарушение архитектурных принципов
- **Проблема:** Python содержит бизнес-логику
- **Статус:** Требует рефакторинга
- **Решение:** Перенести в Go, оставить Python только для AI/аналитики

### 2. Неполная реализация BDUI
- **Проблема:** Frontend статичный, нет динамической отрисовки
- **Статус:** В разработке
- **Решение:** Завершить реализацию в Go backend

### 3. Неполный Go Backend
- **Проблема:** Много заглушек, нет полной реализации
- **Статус:** В разработке
- **Решение:** Завершить перенос логики из Python

## 🛠️ Технологический стек

### Backend
- **Go 1.21+** - ядро системы (бизнес-логика)
- **Gin** - веб-фреймворк
- **GORM** - ORM
- **Python 3.11+** - аналитика и AI
- **FastAPI** - Python веб-фреймворк
- **SQLAlchemy 2** - Python ORM

### Frontend
- **React 18** - UI библиотека
- **TypeScript** - типизация
- **Vite** - сборщик
- **Tailwind CSS** - стили

### Infrastructure
- **Docker** - контейнеризация
- **PostgreSQL 14+** - база данных
- **Ollama** - AI модели
- **ChromaDB** - векторное хранилище
