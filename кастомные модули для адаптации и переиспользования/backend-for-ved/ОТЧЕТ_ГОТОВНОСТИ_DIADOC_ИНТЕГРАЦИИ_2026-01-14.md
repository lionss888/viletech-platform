## Реализованные возможности

### Методы Diadoc API

- ✅ **Аутентификация** через DiadocAuth (ddauth_api_client_id + ddauth_token)
- ✅ **Загрузка документов** (PostMessage V3)
- ✅ **Загрузка XML документов** (PostMessage V3 + XML генерация)
- ✅ **Получение статуса** документов (GetMessage V6)
- ✅ **Скачивание подписанных документов** (GetEntityContent V4)
- ✅ **Поиск организаций по ИНН** (GetOrganizationsByInnKpp)

### Бизнес-функционал (VF-2)

- ✅ **Выбор способа подписи** — `paymentOrderSignMethod`, `reportSignMethod` ('manual' | 'diadoc')
- ✅ **Генерация XML документов** — Invoice, Torg12, AcceptanceCertificate, УПД
- ✅ **Промежуточные статусы** — `REPORT_WAITING_DIADOC`, `WAITING_DIADOC`
- ✅ **3-дневное уведомление** — `DiadocExpirationCheckerService`
- ✅ **Автоприкрепление подписанного PDF** — улучшенный выбор с приоритетами

### Безопасность

- ✅ **Webhook аутентификация** — проверка секрета (timing-safe)
- ✅ **IP whitelist** — поддержка CIDR нотации
- ✅ **Replay protection** — timestamp + nonce cache
- ✅ **Rate limiting** — 10 запросов/минуту на IP
- ✅ **Валидация payload** — проверка структуры

### Дополнительный функционал

- ✅ Обработка webhook-уведомлений от Диадока
- ✅ Периодическая проверка статусов (cron job, fallback для webhook)
- ✅ Retry-механизм с exponential backoff
- ✅ Обработка rate limiting (HTTP 429) с Retry-After
- ✅ Метрики и мониторинг
- ✅ Health check endpoint

### Поддерживаемые типы документов

1. **Поручение на оплату** (Payment Order) — PDF через `uploadDocument()`
2. **Отчёт агента** (Agent Report) — PDF через `uploadDocument()`
3. **Договор** (Contract) — PDF через `uploadDocument()`
4. **Счёт-фактура** (Invoice) — XML через `uploadXmlDocument()`
5. **ТОРГ-12** (Torg12) — XML через `uploadXmlDocument()`

7. **УПД** (UniversalTransferDocument) — XML через `uploadXmlDocument()`

## Конфигурация

Все переменные окружения определены в `src/config.ts` и `.env.example`:

```typescript
diadoc: {
  enabled: stringToBoolean(process.env.DIADOC_ENABLED || 'false'),
  apiUrl: process.env.DIADOC_API_URL || 'https://diadoc-api.kontur.ru',
  apiClientId: process.env.DIADOC_API_CLIENT_ID,
  authToken: process.env.DIADOC_AUTH_TOKEN,
  login: process.env.DIADOC_LOGIN,
  password: process.env.DIADOC_PASSWORD,
  boxId: process.env.DIADOC_BOX_ID,
  timeout: parseInt(process.env.DIADOC_TIMEOUT, 10) || 60000,
  statusCheckInterval: process.env.DIADOC_STATUS_CHECK_INTERVAL || '*/5 * * * *',
  maxRetries: parseInt(process.env.DIADOC_MAX_RETRIES, 10) || 3,
  webhook: {
    secret: process.env.DIADOC_WEBHOOK_SECRET,
    allowedIps: process.env.DIADOC_WEBHOOK_ALLOWED_IPS?.split(','),
    maxAgeSeconds: parseInt(process.env.DIADOC_WEBHOOK_MAX_AGE_SECONDS, 10) || 300,
    validatePayload: stringToBoolean(process.env.DIADOC_WEBHOOK_VALIDATE_PAYLOAD || 'true'),
  },
}
```

## Что требуется для запуска

### 1. Получить ключ разработчика

- Зарегистрироваться на https://developer.kontur.ru/
- Создать приложение
- Получить `ddauth_api_client_id` (GUID)

### 2. Получить BoxId организации

Варианты получения:
- В личном кабинете Диадока
- Через API метод `GetMyOrganizations` (после аутентификации)

### 3. Получить токен аутентификации

Два варианта:
- **Вариант A:** Постоянный токен (если есть) → указать `DIADOC_AUTH_TOKEN`
- **Вариант B:** Логин/пароль → указать `DIADOC_LOGIN` и `DIADOC_PASSWORD` (токен получится автоматически)

### 4. Добавить переменные в `.env`

```bash
# Основные настройки
DIADOC_ENABLED=true
DIADOC_API_CLIENT_ID=ваш-guid-ключа-разработчика
DIADOC_BOX_ID=ваш-box-id@diadoc.ru
DIADOC_AUTH_TOKEN=ваш-токен

# Безопасность webhook
DIADOC_WEBHOOK_SECRET=секретный-ключ-для-webhook
DIADOC_WEBHOOK_ALLOWED_IPS=185.71.76.0/24,185.71.77.0/24
DIADOC_WEBHOOK_MAX_AGE_SECONDS=300
```

### 5. Настроить webhook в Диадоке

- URL: `https://ваш-домен/api/1.0/diadoc/webhook`
- Добавить заголовок: `X-Diadoc-Webhook-Secret: ваш-секрет`
- Для автоматических уведомлений о статусах документов

## API Endpoints

| Метод | URL | Описание |
|-------|-----|----------|
| POST | `/api/1.0/diadoc/webhook` | Webhook для событий от Diadoc (защищён) |
| GET | `/api/1.0/diadoc/health` | Проверка здоровья интеграции |
| GET | `/api/1.0/diadoc/metrics` | Метрики интеграции |
| POST | `/api/1.0/diadoc/check-status` | Принудительная проверка статуса документа |
| PATCH | `/api/1.0/form-payment/:id/sign-method` | Установка способа подписи |
