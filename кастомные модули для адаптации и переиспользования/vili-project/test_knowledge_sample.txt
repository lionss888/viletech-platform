# Тестовый источник знаний для VILI

## FATF (Financial Action Task Force)

FATF (Financial Action Task Force) - международная межправительственная организация, созданная в 1989 году для разработки стандартов и содействия эффективной реализации законодательных, регуляторных и оперативных мер по борьбе с отмыванием денег, финансированием терроризма и финансированием распространения оружия массового уничтожения.

### Основные 40 рекомендаций FATF:

1. **Оценка рисков и применение риск-ориентированного подхода**
   - Страны должны выявлять, оценивать и понимать риски ОД/ФТ
   - Применять риск-ориентированный подход для эффективного использования ресурсов

2. **Национальное сотрудничество и координация**
   - Разработка политики и координация на национальном уровне
   - Обмен информацией между компетентными органами

3. **Отмывание денег как преступление**
   - Криминализация отмывания денег
   - Применимость к широкому кругу предикатных преступлений

4. **Конфискация и временные меры**
   - Полномочия по конфискации преступных доходов
   - Временное замораживание активов

5. **Финансирование терроризма**
   - Криминализация финансирования терроризма
   - Целевые финансовые санкции

## KYC (Know Your Customer)

KYC - процедура идентификации и проверки клиентов, обязательная для финансовых организаций.

### Основные компоненты KYC:

1. **Идентификация клиента (CDD - Customer Due Diligence)**
   - Установление личности клиента
   - Проверка документов, удостоверяющих личность
   - Сбор базовой информации

2. **Проверка бенефициарных владельцев (UBO - Ultimate Beneficial Owner)**
   - Определение конечных выгодоприобретателей
   - Для юридических лиц - владельцы более 25% капитала

3. **Оценка рисков клиента**
   - Определение уровня риска (низкий, средний, высокий)
   - Применение усиленных мер для высокорискованных клиентов

4. **Постоянный мониторинг (Ongoing Monitoring)**
   - Регулярное обновление информации о клиенте
   - Мониторинг транзакций на предмет подозрительной активности

## AML (Anti-Money Laundering)

AML - комплекс мер и процедур по предотвращению отмывания денег.

### Основные этапы отмывания денег:

1. **Размещение (Placement)**
   - Внесение незаконных средств в финансовую систему
   - Наиболее уязвимый этап для обнаружения

2. **Расслоение (Layering)**
   - Проведение сложных финансовых операций
   - Цель: скрыть происхождение средств

3. **Интеграция (Integration)**
   - Возврат средств в легальную экономику
   - Использование в законной деятельности

### Индикаторы подозрительной активности:

- ⚠️ Структурирование транзакций (смурфинг)
- ⚠️ Частые переводы в офшорные зоны
- ⚠️ Несоответствие транзакций профилю клиента
- ⚠️ Отказ предоставить документы
- ⚠️ Использование подставных лиц
- ⚠️ Операции с наличными на большие суммы
- ⚠️ Запутанная структура собственности

## Санкции

Санкции - ограничительные меры, применяемые странами или международными организациями.

### Основные санкционные режимы:

1. **OFAC (Office of Foreign Assets Control) - США**
   - SDN List (Specially Designated Nationals)
   - Секторальные санкции
   - Географические санкции

2. **ООН (United Nations)**
   - Санкции Совета Безопасности ООН
   - Санкции против терроризма
   - Эмбарго на поставки оружия

3. **ЕС (European Union)**
   - Consolidated List of Sanctions
   - Санкции против России
   - Антитеррористические санкции

### Обязанности финансовых организаций:

✅ Проверка клиентов по санкционным спискам
✅ Блокировка транзакций с санкционированными лицами
✅ Отчетность о санкционных совпадениях
✅ Регулярное обновление санкционных списков
✅ Обучение сотрудников

## Типы платежных документов

### SWIFT MT (Message Type)

**MT103 - Single Customer Credit Transfer**
- Самый распространенный тип платежа
- Перевод средств от одного клиента другому
- Используется для международных переводов

**MT202 - General Financial Institution Transfer**
- Перевод между финансовыми учреждениями
- Не содержит информации о клиенте
- Используется для межбанковских расчетов

**MT700 - Issue of a Documentary Credit**
- Аккредитив
- Используется в торговом финансировании

### ISO 20022

Современный международный стандарт для финансовых сообщений:
- Формат XML
- Более богатая структура данных
- Улучшенная прозрачность транзакций
- Обязателен для SEPA с 2023 года

Основные типы сообщений:
- **pacs.008** - Customer Credit Transfer
- **pacs.009** - Financial Institution Credit Transfer
- **pain.001** - Customer Credit Transfer Initiation

## High-Risk Countries (Страны с высоким риском)

Страны, требующие усиленного контроля при проведении транзакций:

### FATF Grey List (Юрисдикции под усиленным мониторингом):
- Афганистан
- Йемен
- Мьянма
- Пакистан
- Сирия
- И другие (список регулярно обновляется)

### FATF Black List (Юрисдикции высокого риска):
- КНДР (Северная Корея)
- Иран

### Признаки высокого риска:
- 🔴 Слабая система AML/CFT
- 🔴 Отсутствие прозрачности бенефициарных владельцев
- 🔴 Офшорные юрисдикции с низкими требованиями
- 🔴 Страны под санкциями
- 🔴 Страны с высоким уровнем коррупции

## Транзакционный мониторинг

### Основные сценарии (scenarios):

1. **Rapid Movement of Funds**
   - Быстрое движение средств через счета
   - Возможное расслоение (layering)

2. **Structuring**
   - Множественные транзакции ниже порога отчетности
   - Цель: избежать отчетности

3. **Round Amount Transactions**
   - Транзакции на круглые суммы
   - Нетипичное поведение для бизнеса

4. **High-Risk Geography**
   - Транзакции с high-risk странами
   - Требуют дополнительной проверки

5. **Sanctions Screening**
   - Совпадения с санкционными списками
   - Автоматическая блокировка

### Действия при выявлении подозрительной активности:

1. Провести углубленную проверку (enhanced due diligence)
2. Собрать дополнительную информацию
3. Проконсультироваться с compliance офицером
4. При подтверждении - подать SAR (Suspicious Activity Report)
5. Документировать все действия
