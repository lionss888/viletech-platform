## ❌ 2. ИСПРАВЛЕННЫЕ ПРОБЛЕМЫ

### ✅ Knowledge Sources API - 500 ошибка (ИСПРАВЛЕНО)

**Проблема:** `GET /api/v1/knowledge-sources/` возвращал 500 Internal Server Error

**Причина:**
- `KnowledgeSourceService` пытался создать `/app/uploads` (Docker путь)
- При локальном запуске путь недоступен

**Решение:**
1. ✅ Исправлен `UPLOAD_DIR` в `config.py`: `./uploads` вместо `/app/uploads`
2. ✅ Создана директория `backend/uploads`
3. ✅ Endpoint теперь работает корректно

**Статус:** ✅ **ИСПРАВЛЕНО И ПРОВЕРЕНО**

## ⚠️ 3. ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

### Некритичные проблемы:

1. **Chat API - медленные ответы (60+ секунд)**
   - **Причина:** CPU режим, модель загружается в память при первом запросе
   - **Решение:** Нормально для CPU. Для продакшена нужен GPU
   - **Статус:** ⚠️ Работает, но медленно

2. **LiteLLM - unhealthy статус в Docker**
   - **Причина:** Healthcheck может не проходить сразу после запуска
   - **Решение:** Сервис работает, но healthcheck требует времени
   - **Статус:** ⚠️ Работает, но требует проверки

3. **TGI (FinGPT) - не запущен**
   - **Причина:** Требует много ресурсов (10-15GB RAM), загрузка 10-15 минут
   - **Решение:** Опционально, не блокирует работу
   - **Статус:** ℹ️ Опционально
