# 🚀 Руководство по запуску проекта VILI

## Два варианта запуска

### 1. 🖥️ Локальный запуск (для разработки)

**Когда использовать:**
- Разработка и отладка
- Быстрая итерация кода
- Локальная машина разработчика

**Требования:**
- Python 3.11+
- PostgreSQL и Redis (можно в Docker)
- Опционально: Docker для LLM сервисов

**Быстрый старт:**

```bash
# Автоматический запуск
./start-local.sh

# Или вручную:
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Запустить БД и Redis в Docker
docker compose up -d postgres redis

# Запустить backend
export DATABASE_URL="postgresql://vili:vili_password@localhost:5432/vili"
export REDIS_URL="redis://localhost:6379/0"
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

**Преимущества:**
- ✅ Быстрый перезапуск (hot reload)
- ✅ Легкая отладка
- ✅ Меньше потребление ресурсов
- ✅ Прямой доступ к логам

**Недостатки:**
- ⚠️ Нужно настраивать окружение вручную
- ⚠️ LLM сервисы лучше запускать в Docker

---

### 2. 🐳 Docker запуск (для серверов и облака)

**Когда использовать:**
- Продакшен серверы
- Облачные развертывания
- CI/CD окружения
- Когда нужна полная изоляция

**Требования:**
- Docker и Docker Compose
- 16GB+ RAM (рекомендуется 32GB)
- 50GB+ свободного места
- Опционально: GPU для TGI

**Быстрый старт:**

```bash
# Полный запуск всех сервисов
./start-docker.sh

# Или через Makefile
make start

# Или напрямую
docker compose up -d
```

**Режимы запуска:**

1. **Полный запуск** (все сервисы):
   ```bash
   docker compose up -d
   ```
   - PostgreSQL, Redis, RabbitMQ
   - Ollama Cluster (2 инстанса + Nginx)
   - LiteLLM
   - TGI (FinGPT) - загрузка 10-15 минут
   - Backend

2. **Быстрый запуск** (без TGI):
   ```bash
   docker compose up -d postgres redis ollama-1 ollama-2 nginx litellm backend
   ```
   - Все сервисы кроме TGI
   - Быстрее, но без FinGPT

3. **Минимальный** (только БД и Backend):
   ```bash
   docker compose up -d postgres redis backend
   ```
   - Только база данных и backend
   - Без LLM сервисов

**Преимущества:**
- ✅ Полная изоляция
- ✅ Легкое развертывание
- ✅ Воспроизводимая среда
- ✅ Готово для продакшена

**Недостатки:**
- ⚠️ Больше потребление ресурсов
- ⚠️ Медленнее перезапуск
- ⚠️ Требует Docker

## 📋 Сравнительная таблица

| Критерий | Локальный | Docker |
|----------|-----------|--------|
| **Скорость запуска** | ⚡ Быстро | 🐌 Медленно (загрузка моделей) |
| **Отладка** | ✅ Легко | ⚠️ Через логи |
| **Hot Reload** | ✅ Да | ❌ Нет (нужна пересборка) |
| **Изоляция** | ⚠️ Зависит от системы | ✅ Полная |
| **Развертывание** | ⚠️ Сложнее | ✅ Проще |
| **Ресурсы** | 💚 Меньше | 💛 Больше |
| **Продакшен** | ❌ Не рекомендуется | ✅ Рекомендуется |

## 🔧 Настройка переменных окружения

### Локальный запуск

Создайте `backend/.env`:
```bash
DATABASE_URL=postgresql://vili:vili_password@localhost:5432/vili
REDIS_URL=redis://localhost:6379/0
LITELLM_URL=http://localhost:4000
OLLAMA_URL=http://localhost:11434
UPLOAD_DIR=./uploads
ENVIRONMENT=development
DEBUG=True
```

### Docker запуск

Переменные задаются в `docker-compose.yml` или через `.env` файл в корне проекта.

## 🐛 Решение проблем

### Проблема: Knowledge Sources API возвращает 500

**Решение:**
```bash
# Создать директорию для загрузок
mkdir -p backend/uploads

# Перезапустить backend
```

### Проблема: Backend не подключается к БД

**Решение:**
```bash
# Проверить, что PostgreSQL запущен
docker compose ps postgres

# Проверить подключение
docker exec vili-db pg_isready -U vili -d vili
```

### Проблема: LLM сервисы не отвечают

**Решение:**
```bash
# Проверить статус Ollama
curl http://localhost:11434/api/tags

# Проверить логи
docker compose logs ollama-1 ollama-2

# Перезапустить
docker compose restart ollama-1 ollama-2 nginx
```

## 🎯 Рекомендации

### Для разработки:
- Используйте **локальный запуск** для backend
- PostgreSQL и Redis в Docker
- LLM сервисы в Docker (опционально)

### Для продакшена:
- Используйте **Docker запуск**
- Настройте reverse proxy (Nginx/Traefik)
- Добавьте мониторинг (Prometheus/Grafana)
- Настройте GPU для LLM сервисов
