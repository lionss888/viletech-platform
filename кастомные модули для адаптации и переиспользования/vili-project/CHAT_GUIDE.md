# 🤖 Руководство по использованию VILI веб-интерфейсов

## 🎯 Быстрый старт

После запуска системы (`make start`) доступны два веб-интерфейса:

### 1. 💬 Чат с AI-ассистентом
**URL:** http://localhost:8000/chat/

Простой интерфейс для общения с AI-ассистентом VILI.

#### Возможности:
- ✅ Задавать вопросы о финансовых регуляциях
- ✅ Анализировать платежные документы
- ✅ Получать информацию о compliance требованиях
- ✅ Загружать документы для анализа
- ✅ Использовать базу знаний (RAG) для точных ответов

#### Как использовать:

1. **Простые вопросы:**
   ```
   Что такое FATF рекомендации?
   Как проверить санкционный список?
   Какие риски у транзакции в Россию?
   ```

2. **Анализ документов:**
   - Нажмите "📎 Файл"
   - Выберите файл (PDF, TXT, CSV, XML, JSON)
   - Введите вопрос о документе
   - Нажмите "Отправить"

3. **Настройки:**
   - **Модель LLM:** выберите модель для ответов
     - `Llama 3.2` - основная локальная модель
     - `Qwen 2.5 7B` - альтернативная модель (если загружена)
     - `FinGPT Sentiment` - специализированная финансовая модель
   
   - **База знаний (RAG):** включите для использования загруженных источников
   - **Температура:** 0.0-1.0 (0.3 для точности, 0.7 для креативности)
   - **Макс. токенов:** количество токенов в ответе (500-4000)

#### Примеры запросов:

```
📌 Общие вопросы:
- Объясни что такое AML
- Какие документы нужны для KYC проверки?
- Что такое SWIFT MT103?

📌 Compliance:
- Как проверить компанию на санкции?
- Требования FATF к финансовым учреждениям
- Процедура due diligence для клиентов

📌 Анализ рисков:
- Какие риски при работе с high-risk странами?
- Как оценить риск транзакции?
- Индикаторы подозрительной активности
```

### 2. 📚 Админ-панель базы знаний
**URL:** http://localhost:8000/admin/

Интерфейс для управления источниками знаний, которые использует AI-ассистент.

#### Возможности:
- ➕ Добавление источников знаний (URL или файлы)
- 📄 Просмотр загруженных источников
- 🔄 Обновление источников
- 🗑️ Удаление источников
- 👁️ Просмотр фрагментов (chunks) документов

#### Как добавить источник знаний:

**Способ 1: По URL**
1. Перейдите на вкладку "По URL"
2. Заполните:
   - **Название:** например "FATF рекомендации"
   - **URL:** https://example.com/fatf-recommendations.pdf
   - **Описание:** краткое описание
   - **Автообновление:** ✓ (опционально)
3. Нажмите "Добавить источник"

**Способ 2: Загрузить файл**
1. Перейдите на вкладку "Загрузить файл"
2. Заполните:
   - **Название:** например "Санкционный список"
   - **Файл:** выберите PDF, CSV, TXT, JSON или XML
   - **Описание:** краткое описание
3. Нажмите "Загрузить источник"

#### Поддерживаемые форматы:
- 📄 **PDF** - документы, отчеты, руководства
- 📊 **CSV** - списки, таблицы данных
- 📝 **TXT** - текстовые документы
- 🔧 **JSON** - структурированные данные
- 📋 **XML** - XML документы

#### Примеры источников знаний:

```
✅ Регуляторные документы:
- FATF рекомендации
- Директивы ЕС по AML
- Требования ЦБ РФ

✅ Санкционные списки:
- OFAC SDN List
- EU Sanctions List
- UN Sanctions List

✅ Внутренние политики:
- Политика KYC
- Процедуры AML
- Правила обработки транзакций

✅ Справочники:
- Список стран с высоким риском
- Коды валют ISO 4217
- Типы платежных документов
```

## 🧪 Тестирование функциональности

2. Включите "Использовать базу знаний (RAG)"
3. Спросите: "Что такое FATF?"
4. Проверьте, что получили ответ

### Тест 2: Добавление источника знаний
1. Откройте http://localhost:8000/admin/
2. Создайте тестовый файл `test_knowledge.txt`:
   ```
   FATF (Financial Action Task Force) - международная межправительственная организация,
   разрабатывающая стандарты по борьбе с отмыванием денег и финансированием терроризма.
   
   Основные рекомендации FATF:
   1. Проведение оценки рисков
   2. Применение мер по идентификации клиентов (KYC)
   3. Ведение записей транзакций
   4. Сообщение о подозрительных операциях
   ```
3. Загрузите файл через "Загрузить файл"
4. Проверьте, что источник появился в списке

### Тест 3: Использование базы знаний в чате
1. После загрузки источника (Тест 2)
2. Вернитесь в чат: http://localhost:8000/chat/
3. Убедитесь, что "Использовать базу знаний (RAG)" ✓
4. Спросите: "Какие основные рекомендации FATF?"
5. Проверьте, что ответ содержит информацию из загруженного файла
6. Внизу ответа должна быть метка: "✓ Использована база знаний"

## 🐛 Решение проблем

### Проблема: "Model list not initialized" в LiteLLM
**Решение:** 
```bash
# Проверьте конфигурацию
cat litellm_config.yaml

# Перезапустите LiteLLM
docker restart vili-litellm
```

### Проблема: Чат не отвечает
**Решение:**
```bash
# Проверьте статус Ollama
curl http://localhost:11434/api/tags

# Проверьте логи backend
make logs-backend
```

### Проблема: Не загружаются файлы в базу знаний
**Решение:**
```bash
# Проверьте права доступа
ls -la backend/app/static/

# Проверьте логи
make logs-backend

# Проверьте базу данных
make db-status
```

## 📊 API Endpoints (для разработчиков)

### Chat API:
- `POST /api/v1/chat/message` - Отправить сообщение
- `GET /api/v1/chat/models` - Список моделей

### Knowledge Base API:
- `GET /api/v1/knowledge-sources/` - Список источников
- `POST /api/v1/knowledge-sources/` - Добавить URL источник
- `POST /api/v1/knowledge-sources/upload` - Загрузить файл
- `GET /api/v1/knowledge-sources/{id}/chunks` - Просмотр фрагментов
- `POST /api/v1/knowledge-sources/{id}/refresh` - Обновить источник

### Документация API:
- Swagger UI: http://localhost:8000/api/docs
- ReDoc: http://localhost:8000/api/redoc
