# Перенос среды Cursor

Сюда складывается то, что **не живёт в обычных файлах проекта**: чаты агента, layout, settings, keybindings, транскрипты.

Репозиторий должен быть **приватным** — в снимке есть история диалогов.

## Туда

На исходной машине:

```sh
./перенос-среды/собрать.sh
git add перенос-среды/snapshot
git commit -m "снимок среды Cursor"
git push
```

Cursor можно не закрывать.

## Обратно

На другой машине:

1. `git pull`
2. Открыть `viletech-platform.code-workspace` в Cursor (один раз, чтобы появилось хранилище)
3. **Полностью выйти** из Cursor
4. `./перенос-среды/развернуть.sh`
5. Снова открыть тот же `.code-workspace`

Путь клону может отличаться — скрипт перепишет пути и id воркспейса.

Не копируются: токены MCP, секреты OAuth, чаты других проектов.
