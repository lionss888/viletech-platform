# Источники и ссылки (VDP Role Wording / справочники)

Назначение: официальная база терминов и реестров для копирайта UI и будущих справочников платформы.
Status id / action id в core не меняем — только UI-проекция и подсказки «источник».

## 1. Портал ВЭД
URL: https://ved.gov.ru/#/
Использование:
- Официальная терминология участника ВЭД
- Процессы и формулировки для кабинета клиента (User)
- Контекст «участник внешнеэкономической деятельности»

## 2. Реестры / открытые данные Минфина
URL: https://minfin.gov.ru/ru/opendata/registry/
Использование:
- Справочники и открытые данные для подписей в UI
- Согласование названий реестров / организаций с официальными формулировками

## 3. Инфраструктура финансового рынка (Банк России)
URL: https://cbr.ru/registries/infrastr/
Использование:
- Лексика финрынка и платёжной инфраструктуры
- Копирайт Bank channel (RW8) и Manager payment (RW5)
- Tooltips «источник: Банк России» где уместно

## 4. Товарная номенклатура ТН ВЭД (ФТС)
URL: https://customs.gov.ru/uchastnikam-ved/spravochnaya-informacziya/tovarnaya-nomenklatura-%28tn-ved-eaes-i-tn-ved-sng%29
Использование:
- Коды ТН ВЭД ЕАЭС / СНГ
- Таможенная лексика в справочнике `/codes` и полях заявки
- Tooltips «источник: ФТС / ТН ВЭД»

## 5. Методология (учебное пособие)
Источник: Ксенофонтова Е. М. «Основы внешнеэкономической деятельности» (2017)
Локальные артефакты:
- osnovy-ved-konspekt.txt
- terminologiya-ved.txt
- glossariy-po-rolyam.txt

## Правила применения в продукте
1. Не подменять канонические id статусов/действий домена.
2. Один термин на сущность внутри кабинета роли (см. ui-web-практики).
3. Provider-кабинет: без ПДн клиента (см. безопасность-ролей-и-данных).
4. Root / суперадмин — вне scope ветки Role Wording (RW*).
