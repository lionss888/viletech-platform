# Глоссарий по ролям (черновик Role Wording)
Канон = status id / action id / UI-сущность. Меняем только label/subtitle/empty/confirm.
Root (суперадмин) — вне scope. «—» = не показывать / не переопределять для роли.

Формат: канон | сейчас (общее) | user | ico | eco | manager | provider | bank

## Навигация / фокус (черновик)
dashboard focus user | Ваши сделки, документы к загрузке и статусы платежей.
dashboard focus ico | Проверка организаций и заявок перед запуском сделки.
dashboard focus eco | Внешняя проверка заявок и подтверждение условий сделки.
dashboard focus manager | Договоры, поручения, платежи и отгрузка по всем сделкам.
dashboard focus provider | Сделки, переданные в исполнение платежа (без данных клиента).
nav forms user | Мои заявки / Реестр заявок
nav forms compliance | Входящие на проверку
nav orgs compliance | Проверка организаций

## Правила обновления
1. Правки только после сверки с terminologiya-ved.txt и istochniki-i-ssylki.txt.
2. Не плодить синонимы внутри одной роли (заявка vs сделка — выбрать primary для роли).
3. Provider: запрещены ownerName, ФИО, паспорт, личные контакты в copy.
4. Финализация формулировок — в исполнении RW1–RW8; этот файл — living draft.
