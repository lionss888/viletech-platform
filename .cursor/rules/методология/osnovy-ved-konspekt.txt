# Конспект: Основы внешнеэкономической деятельности
Источник: Ксенофонтова Е. М. «Основы внешнеэкономической деятельности». СПб.: ИЦ Интермедия, 2017.
Назначение: опорный конспект для копирайта VDP (не полный OCR книги).

## Принятые сокращения (из пособия)
ВЭД — внешнеэкономическая деятельность
ВТО — Всемирная торговая организация
ЕАЭС — Евразийский экономический союз
ИНКОТЕРМС — международные правила толкования торговых терминов
ТН ВЭД — товарная номенклатура внешнеэкономической деятельности
ФТС — Федеральная таможенная служба
ЦБ — Центральный банк

## Структура пособия (ориентир)
Раздел I. Общие вопросы ВЭД
  Гл. 1. Понятие, сущность, особенности ВЭД; субъекты и объекты
  Гл. 2. Государственное воздействие на внешнюю торговлю; цели, принципы, инструменты

Раздел II. Внешняя торговля и посредники
  Гл. 3. Международная торговая сделка; оформление
  Гл. 4. Внешнеэкономические операции; техника исполнения
  Гл. 5. Документальное обеспечение; ИНКОТЕРМС; риски; страхование
  Гл. 6. Рынок услуг; торгово-посреднические операции; транспорт

Приложение: терминологический словарь (см. terminologiya-ved.txt)

## Ключевые понятия для платформы
1. ВЭД — сделки во внешней торговле товарами/услугами/ИП + инвестиционное и иное сотрудничество.
2. Внешнеторговый контракт — основной коммерческий документ сделки.
3. Посредники: агентские, комиссионные, брокерские операции — важны для кабинета Manager (агент, поручение принципала).
4. Документы сделки: инвойс, контракт, транспортные/таможенные документы — ветки upload User.
5. Валютно-финансовые условия: валюта цены / валюта платежа — поля заявки и payment flow.
6. Государственное регулирование и комплаенс — кабинеты ICO/ECO (проверка организации и заявки).

## Что НЕ тащим в UI из пособия
- Учебные формулировки «для студента»
- Устаревшие институциональные названия без сверки с актуальными реестрами (ved.gov.ru, cbr.ru, customs.gov.ru, minfin)
- Полный текст глав — только термины и смысл процесса

## Связь с кабинетами VDP
User — участник ВЭД / клиент сделки: заявка, документы, статусы «что дальше»
ICO — внутренняя проверка организации и заявки
ECO — внешняя проверка условий/документов сделки
Manager — операционное сопровождение: агент, договор, поручение, платёж, отчёт, отгрузка
Provider — исполнение платежа по реквизитам (без ПДн клиента)
Bank — канал банковской инфраструктуры / API
Root — вне scope Role Wording
