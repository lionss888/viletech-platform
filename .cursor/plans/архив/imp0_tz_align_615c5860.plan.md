# IMP0 — ТЗ и инварианты импортных маршрутов

Источник: [`вводные/Маршрут постоплатный импорт.docx`](вводные/Маршрут%20постоплатный%20импорт.docx). База: [`вводные/вводные от ви.txt`](вводные/вводные%20от%20ви.txt), [`вводные/расширение вводных.txt`](вводные/расширение%20вводных.txt). Код не трогаем в этом этапе.

## Решения (зафиксировать в тексте вводных)

- **Аванс импорт:** курс + вознаграждение → поручение → подпись → рубли клиента → **казначей подтверждает покрытие** → провайдер → отчёт.
- **Постоплата импорт:** `platform_postpay_mode = POSTPAY_RATE_ON_PP`. Primary-поручение **без курса** (допустим % вознаграждения) → подпись → **провайдер до рублей клиента** → ПП → курс + вознаграждение → доп. поручение → рубли → казначей → отчёт.
- **Конфликт §3.6 расширения:** для импорта `POSTPAY_RATE_ON_PP` порядок денег из doc **переопределяет** «клиент платит до провайдера». Записать явным абзацем в расширении.
- **Роли:** Клиентский менеджер = `Manager`; Казначей = `Treasurer` (новый смысл на импорте, не только export `PAY_FROM_EXPORT`); ICO/ECO/договор/ПА — из ВИ, doc их не отменяет.
- **Комиссия:** три режима (фикс / % / %+фикс) — контракт для IMP3; в IMP0 только описание.
- **Вне scope пакета:** `POSTPAY_FIXED_RATE`, экспортный overpay-treasurer, логистика, Diadoc/OCR на money-path.

## Deliverable

Короткий аддендум в [`вводные/расширение вводных.txt`](вводные/расширение%20вводных.txt) (секция «Импорт: аванс и RATE_ON_PP») + правка §3.6. Без новых markdown-доков в `vdp/docs` без нужды.
