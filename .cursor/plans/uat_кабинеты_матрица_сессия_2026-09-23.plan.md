# UAT кабинеты: матрица приёмки (сессия 2026-09-23)

## Запрос

Проверить работу всех участников кабинетов как тестировщик (клиент, менеджер, провайдер, CO, казначей, root). Сценарии — все, связанные с заявкой. Типы заявок — все. Документы — `вводные/примеры документов`. Feedback → волны доработок (1 волна = 1 план).

## Контур

- App: `http://localhost:5173` (не `/demo`)
- Seed: `*@vdp.local` / пароль = local-part
- Compose already up (core, fe, extraction, docling, …)

## Сверка с `.cursor/rules`

**Обязательны:** `планирование-сверка-с-rules`, `базовые-правила-инструмента`, `честность-готовности`, `ui-проблема-сразу-воспроизведи` (сначала живой repro), `ui-web-практики`, `ux-*`, `fe-interaction-contracts` (upload через жест), `playwright-e2e`, `use-cases`, `безопасность-ролей-и-данных` (Provider без ПДн), `интеграция-и-события` (UI = проекция статуса), `машинное-обучение` (OCR side-path, HITL), `vdp-ci-local-gate`, `mgmt-tg-notify` при закрытии волны.

**Вне scope этой сессии (не менять без волны):** смена статусной машины ради «удобства теста»; auto-pay по OCR; shared DB хаки.

**Gate на волну фикса:** зависит от поверхности волны; минимум `check-env-parity` + unit затронутого; UI journey → `ci-pr` / `ci-pr-pilot` / `ci-main` по path-filter (`vdp-ci-local-gate`).

## Типы заявок (продукт)

| Ось | Значения |
|---|---|
| direction | import, export |
| kind | good, service |
| condition | advance, postPayment |

Итого 8 комбинаций для create/submit smoke; полный ladder — на приоритетных (import×good×advance, import×good×postPayment, export×good×advance).
